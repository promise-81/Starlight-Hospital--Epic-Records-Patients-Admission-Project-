### Project Overview

This project aims to provide actionable insights for Healthcare Management and efficiency for Starlight general hospital (2022-2024). By Analysing various variables of the data, to identify occupancy rate, waiting times, readmission rate, denial rate, collection rate, Revenue Cycle Trends, and to gain deeper understanding of the operations efficiency within the hospital.

**Disclaimer** *I created this dataset and theses records and hospital does not exist.*
